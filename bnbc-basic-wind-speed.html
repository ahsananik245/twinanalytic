BNBC 2020 · Wind

Basic wind speed by location

A 3-second gust at 10 m in Exposure B for a 50-year return period. Drop any one of those qualifiers and the number stops meaning what the Code intends.

What the table actually gives

BNBC 2020 Table 6.2.8 lists the basic wind speed V for locations across Bangladesh. Four qualifiers travel with every number in it, and dropping any one of them changes the answer:

  • a 3-second gust, not a sustained or hourly mean
  • at 10 m above ground
  • in Exposure B
  • for a 50-year mean recurrence interval

A speed quoted from a weather report, a cyclone bulletin or another country's code is none of these things and cannot be substituted.

Across the full table the values run from 41.4 m/s at Chapai Nawabganj to 80.0 m/s on the south-eastern coast — Barguna, Chittagong, Cox’s Bazar and Maheshkhali among them. That is a factor of about 1.93 in speed, and because pressure goes with the square of velocity, roughly 3.7× in load between the calmest and the most exposed sites in the country.

It is the single clearest argument against carrying a wind pressure over from a previous project in a different district.

Two rules for reading it

Do not interpolate between towns. The table is a list of discrete locations, not a surface to sample. For a site that is not listed, use the nearest listed location or read the wind speed map — that is what the Code directs, and averaging two neighbouring towns is not a defensible substitute.

Check the importance factor separately. The occupancy importance factor for wind changes in cyclone-prone areas, so the same building type does not carry the same factor everywhere the speed is high.
